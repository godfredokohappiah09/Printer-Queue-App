What the queue just did

    Why the queue is important in this app

    • Fairness. Jobs print in the order they arrive, so a person who sent a document first is never pushed aside by someone who sent one later.
    • No lost jobs. The printer handles one job at a time, but people send jobs at any moment. The queue holds the extra jobs safely until the printer is free.
    • Order is kept. Enqueue always adds at the back and dequeue always takes from the front, so the order of printing is predictable.
    • Speed. Adding and removing a job are both quick actions, even when many jobs are waiting.

    The queue code behind the app

    class Queue {
  constructor() { this.items = []; }
  enqueue(job)  { this.items.push(job); }          // add at the back
  dequeue()     { return this.items.shift(); }     // remove from the front
  peek()        { return this.items[0]; }          // look at the front
  isEmpty()     { return this.items.length === 0; }
  size()        { return this.items.length; }
}
